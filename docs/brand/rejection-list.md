# Space Zero — Rejection List

This file defines what Space Zero should not become.

## Visual

* No purple AI gradients
* No gradient text
* No neon cyberpunk
* No glassmorphism
* No excessive rounded cards
* No generic SaaS dashboard aesthetic
* No excessive shadows
* No decorative UI without purpose
* No three-column feature grids
* No emoji as primary interface icons
* No generic AI robot imagery
* No excessive airplane or globe imagery
* No stock-photo-heavy interface

## Copy

Avoid generic AI and startup language.

Do not use:

* "Unlock your travel potential"
* "The future of travel"
* "Revolutionizing travel"
* "Your AI-powered travel companion"
* "Seamless travel experience"
* "Transform your journey"
* "Travel smarter, not harder"

Prefer concrete language that describes what Space Zero actually does.

## Product

* Do not make the user manage the agent
* Do not turn the product into a chatbot-only experience
* Do not add unnecessary travel marketplace features
* Do not expose technical complexity that the user does not need
* Do not ask for confirmation for every minor action
* Do not allow autonomous actions outside the user's defined authority

## Engineering

* No unnecessary microservices
* No unnecessary databases
* No premature abstractions
* No complex infrastructure unless required
* No fake integrations
* No simulated transactions presented as real transactions

## Core Test

If a feature, visual element, or piece of copy does not make Space Zero clearer, more trustworthy, or more useful, remove it.
