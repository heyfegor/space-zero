# Space Zero — Logo Direction

## Brand

**Space Zero**

## Concept

The logo should communicate the idea of **space, movement, coordination, and a clear path through complexity**.

The name suggests a starting point: before the journey begins, the user gives Space Zero the problem and the agent takes over the coordination.

## Direction

The mark should be:

* Simple
* Distinctive
* Geometric
* Recognizable at small sizes
* Strong enough to work as an app icon
* Appropriate for a serious global travel product

## Potential Concept

Explore an abstract symbol built around:

* A route
* A point-to-point path
* An orbital movement
* A zero
* A controlled trajectory

The concept should feel like a **system in motion**, not a literal airplane.

## Avoid

* Airplane icons
* Globes
* Location pins
* Generic AI sparkles
* Robot imagery
* Excessive gradients
* Overly complex symbols
* Generic lettermark treatment

## Wordmark

"Space Zero" should have a clean, confident wordmark.

Typography should feel modern, precise, and editorial rather than playful or futuristic.

## Usage

The identity must work in:

* Product navigation
* Mobile app icon
* Website
* Favicon
* Demo video
* Social profiles
* Dark and light interfaces

## Design Principle

**The logo should represent the system, not the category.**

It should still feel like Space Zero if the viewer does not immediately know it is a travel product.
