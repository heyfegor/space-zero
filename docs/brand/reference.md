# Space Zero — Reference

## Primary Reference

**Muse Mirror**

https://musemirror.app/

Muse Mirror is the primary creative/product reference for Space Zero's design philosophy.

We are not copying its visual identity, interface, branding, or assets.

We are studying its product thinking.

---

## What We Learn From Muse Mirror

### 1. Judgment Before Output

Muse Mirror does not begin with pixels.

It first understands the project, audience, tension, metaphor, and visual direction.

**Space Zero principle:**

The agent should understand the user's travel objective and constraints before taking action.

```text
User intent
    ↓
Understand
    ↓
Reason
    ↓
Act
```

Not:

```text
Prompt
    ↓
Generic response
```

---

### 2. Position Before Production

Muse Mirror gives users distinct creative territories and lets them choose a direction before production.

**Space Zero equivalent:**

The agent should establish the travel strategy before executing.

```text
Travel requirements
    ↓
Possible strategies
    ↓
Best itinerary
    ↓
User authority
    ↓
Execution
```

The product should make the agent's reasoning and chosen strategy understandable.

---

### 3. Critic Before Delivery

Muse Mirror evaluates generated work before delivering it.

**Space Zero equivalent:**

Before executing an important action, the agent should validate:

* Does this satisfy the user's requirements?
* Is it within budget?
* Is it within the user's authority?
* Does it still satisfy the arrival requirement?
* Does the action create a new problem?

```text
Agent decision
    ↓
Validate
    ↓
Within constraints?
   ↙        ↘
 YES        NO
  ↓          ↓
Execute    Reconsider / Escalate
```

This is a core product principle.

---

### 4. Complexity Absorption

Muse Mirror hides creative complexity from the user.

The user gives a simple brief while the system handles the complicated work underneath.

**Space Zero should do the same.**

The user should say:

> "Get me to London before Friday morning."

They should not need to manually coordinate:

* Flight search
* Connections
* Ground transport
* Booking
* Payment
* Monitoring
* Rebooking

The agent absorbs that complexity.

---

### 5. One System, Many Outputs

Muse Mirror maintains one creative direction across different formats.

**Space Zero equivalent:**

The user's original travel requirements should remain the source of truth throughout the journey.

```text
Original trip intent
        ↓
Planning
        ↓
Booking
        ↓
Monitoring
        ↓
Disruption handling
        ↓
Recovery
```

A disruption should not cause the agent to forget the original objective.

---

## What We Do NOT Copy

Do not copy:

* Muse Mirror's logo
* Muse Mirror's typography
* Muse Mirror's color palette
* Muse Mirror's exact layouts
* Muse Mirror's copy
* Muse Mirror's illustrations
* Muse Mirror's interface
* Muse Mirror's visual metaphors

The reference is about **product philosophy and design discipline**, not imitation.

---

## Space Zero Design Translation

Muse Mirror:

**Creative director that happens to render.**

Space Zero:

**Travel operator that happens to be an AI agent.**

Muse Mirror's principle:

**The judgment comes first; the pixels are the consequence.**

Space Zero's equivalent:

**The decision comes first; the action is the consequence.**

---

## Quality Bar

Every major Space Zero experience should pass four questions:

1. Does the system understand what the user actually wants?
2. Does it make a defensible decision?
3. Does it validate that decision against the user's rules?
4. Does it execute or escalate appropriately?

If the answer is no, the experience is not ready.

---

## Reference Rule

When designing Space Zero, ask:

**"What would the Muse Mirror approach look like if the output were a completed travel journey instead of a creative asset?"**

That question should guide product thinking without turning Space Zero into a copy of Muse Mirror.
